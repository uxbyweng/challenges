Bitte sortieren
Deine Aufgabe ist es, eine gegebene Zeichenkette zu sortieren. Jedes Wort in der Zeichenkette enthält eine einzelne Zahl. Diese Zahl gibt die Position an, an der das Wort im Ergebnis stehen soll.

Hinweis: Die Zahlen liegen im Bereich von 1 bis 9. Die 1 steht also für das erste Wort (nicht die 0).

Ist die Eingabezeichenkette leer, gib eine leere Zeichenkette zurück. Die Wörter in der Eingabezeichenkette enthalten ausschließlich gültige, aufeinanderfolgende Zahlen.

Examples
"is2 Thi1s T4est 3a" --> "Thi1s is2 3a T4est"
"4of Fo1r pe6ople g3ood th5e the2" --> "Fo1r the2 g3ood 4of th5e pe6ople"
"" --> ""
